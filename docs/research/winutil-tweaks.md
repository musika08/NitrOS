# winutil tweak inventory for NitrOS

Source: https://github.com/ChrisTitusTech/winutil (MIT License, Copyright Chris Titus Tech; keep MIT credit when reusing). Read at commit `2f0bdc8fca52e1ebe31a8d98216428061d3f8956` (main). Files: `config/tweaks.json`, `config/appx.json`, `config/feature.json`, `config/preset.json`, `config/dns.json`, `functions/private/Remove-WinUtilAPPX.ps1`, `Remove-WinUtilProvisionedAPPX.ps1`, `Install-WinUtilAPPX.ps1`.

Identifiers, registry paths, values, service names and package IDs are copied verbatim from the JSON. The category, RAM/process effect and risk columns are our assessment unless marked "per its text" (quoted from winutil). Undo: y = unchecking in winutil reverses it (registry OriginalValue / service OriginalType / UndoScript); partial = only the registry/service part reverts; n = no undo.

Registry notes: for toggles, `Value` is applied when ON, `orig` when OFF. `<RemoveEntry>` = value deleted on undo. `HKLM:`/`HKCU:` prefixes are as in source. Long scripts are whitespace-collapsed.

### Winutil descriptions (verbatim)

- `WPFTweaksActivity`: Stops Windows from publishing or uploading user activities while preserving clipboard history.
- `WPFTweaksHiber`: Hibernation is really meant for laptops as it saves what's in memory before turning the PC off. It really should never be used.
- `WPFTweaksWidget`: Removes the annoying widgets in the bottom left of the Taskbar.
- `WPFTweaksRevertStartMenu`: Bring back the old Start Menu layout from before the gradual rollout of the new one in 25H2. On newer versions of Windows !!THIS TWEAK WILL NOT WORK!!
- `WPFTweaksDisableStoreSearch`: Will not display recommended Microsoft Store apps when searching for apps in the Start menu.
- `WPFTweaksLocation`: Disables Location Tracking.
- `WPFTweaksServices`: Sets some services to Manual startup.
- `WPFTweaksSvcHostSplitting`: Disables service-host splitting to reduce the number of svchost.exe processes and modestly lower memory overhead. Recommended for low-performance systems with 12 GB of RAM or less. Can interfere with Xbox services. Restart Windows after changing this setting.
- `WPFTweaksBraveDebloat`: Disables various annoyances like Brave Rewards, Leo AI, Crypto Wallet and VPN.
- `WPFTweaksDisableWarningForUnsignedRdp`: Disables warnings shown when launching unsigned RDP files introduced with the latest Windows 10 and 11 updates.
- `WPFTweaksEdgeDebloat`: Disables various telemetry options, popups, and other annoyances in Edge.
- `WPFTweaksConsumerFeatures`: Stops promoted app installs and reduces app suggestions from Microsoft Store content.
- `WPFTweaksTelemetry`: Disables Microsoft Telemetry.
- `WPFTweaksDeliveryOptimization`: Stops Windows from using your bandwidth to upload updates to other PCs on the internet or local network.
- `WPFTweaksRemoveEdge`: Uninstalls Microsoft Edge by creating dummy MicrosoftEdge.exe file in the legacy Edge folder. This tricks Windows into unlocking the official Edge uninstaller allowing for a system-level removal.
- `WPFTweaksDisableBitLocker`: Disables BitLocker.
- `WPFTweaksUTC`: Essential for computers that are dual booting. Fixes the time sync with Linux systems.
- `WPFTweaksRemoveOneDrive`: Denies permission to remove OneDrive user files, then uses its own uninstaller to remove it and restores the original permission afterward.
- `WPFTweaksRemoveHomeAndGallery`: Removes the Home and Gallery from Explorer and sets This PC as default.
- `WPFTweaksDisplay`: Sets the system preferences to performance. You can do this manually with sysdm.cpl as well.
- `WPFTweaksReservedStorage`: Disables Windows Reserved Storage (7-10 GB held for updates/temp files). Recommended only on small drives. Re-enable before major Windows feature updates to avoid installation failures.
- `WPFTweaksRestorePoint`: Creates a restore point at runtime in case a revert is needed from WinUtil modifications.
- `WPFTweaksEndTaskOnTaskbar`: Enables option to end task when right-clicking a program in the taskbar.
- `WPFTweaksStorage`: Storage Sense deletes temp files automatically.
- `WPFTweaksWindowsAI`: Removes and disables all AI features/packages
- `WPFTweaksWPBT`: If enabled, WPBT allows your computer vendor to execute programs at boot time, such as anti-theft software, software drivers, as well as force install software without user consent. Poses potential security risk.
- `WPFTweaksPreventDeviceMetadataFromNetwork`: Prevents additional software from being installed when plugging in devices (e.g. Ads when plugging in a monitor). Poses potential security risk.
- `WPFTweaksRazerBlock`: Blocks ALL Razer Software installations. The hardware works fine without any software.
- `WPFTweaksLogiBlock`: Blocks the Logi Download Assistant that Windows Update keeps reinstalling with Logitech device drivers. Logitech hardware keeps working without it.
- `WPFTweaksDisableNotifications`: Disables all Notifications INCLUDING Calendar.
- `WPFTweaksBlockAdobeNet`: Reduces user interruptions by selectively blocking connections to Adobe's activation and telemetry servers. Credit: Ruddernation-Designs
- `WPFTweaksRightClickMenu`: Restores the classic context menu when right-clicking in File Explorer, replacing the simplified Windows 11 version.
- `WPFTweaksDiskCleanup`: Runs Disk Cleanup on Drive C: and removes old Windows Updates.
- `WPFTweaksDeleteTempFiles`: Erases TEMP Folders.
- `WPFTweaksIPv46`: Setting the IPv4 preference can have latency and security benefits on private networks where IPv6 is not configured.
- `WPFTweaksTeredo`: Teredo network tunneling is an IPv6 feature that can cause additional latency, but may cause problems with some games.
- `WPFTweaksDisableIPv6`: Disables IPv6.
- `WPFTweaksDisableBGapps`: Disables all Microsoft Store apps from running in the background, which has to be done individually since Windows 11.
- `WPFTweaksDisableExplorerAutoDiscovery`: Windows Explorer automatically tries to guess the type of the folder based on its contents, slowing down the browsing experience. WARNING! Will disable File Explorer grouping.
- `WPFToggleDetailedBSoD`: Gives more information when you blue screen.
- `WPFToggleBatteryPercentage`: Shows numeric battery percentage next to the battery icon in the system tray.
- `WPFToggleDarkMode`: Dark Mode for the system and applications.
- `WPFToggleShowExt`: Shows .file extensions in Explorer (.exe, .png, etc.)
- `WPFToggleHiddenFiles`: Reveals hidden files in Explorer.
- `WPFToggleVerboseLogon`: Show detailed messages during startup/shutdown.
- `WPFToggleNewOutlook`: This will ensure the new Outlook application is used.
- `WPFToggleScrollbars`: If enabled, scrollbars will always be visible. If disabled, Windows will automatically hide scrollbars when not in use.
- `WPFMultiplaneOverlay`: Multiplane Overlay composes multiple image layers, which can sometimes cause issues with graphics cards. Changes to this preference are applied immediately.
- `WPFToggleMouseAcceleration`: Makes it so Cursor movement is affected by the speed of your physical mouse movements.
- `WPFToggleNumLock`: Toggle the Num Lock key state when your computer starts.
- `WPFToggleWindowSnapping`: Toggles the window snapping feature when dragging windows.
- `WPFToggleStandbyFix`: Toggles network connectivity during S0 Sleep which is low power idle in modern laptops.
- `WPFToggleS3Sleep`: Toggles between Modern Standby and S3 Sleep, which cuts off power to the CPU while continuing to refresh the memory.
- `WPFToggleHideSettingsHome`: Toggles the Home Page in the Windows Settings app.
- `WPFToggleBingSearch`: Toggles Bing web search results in Windows Search.
- `WPFToggleLoginBlur`: Toggles the acrylic blur effect on login screen background.
- `WPFToggleDisableLockscreen`: Skips the lock screen entirely and goes directly to the sign-in screen on boot and wake.
- `WPFToggleStartMenuRecommendations`: Toggles the recommendations section in the Start Menu. WARNING: This will also disable Windows Spotlight on your Lock Screen as a side effect.
- `WPFToggleStickyKeys`: Toggles the Sticky Keys, which activate when clicking shift rapidly.
- `WPFToggleTaskbarAlignment`: Toggles the Taskbar alignment either to the left or center.
- `WPFToggleTaskbarSearch`: Toggles the Search Button on the Taskbar.
- `WPFToggleTaskView`: Toggles the Task View Button in the Taskbar.
- `WPFToggleGameMode`: Toggles Windows prioritizes gaming performance by allocating system resources to games.
- `WPFToggleLongPaths`: Toggles support for file paths longer than 260 characters in Explorer.
- `WPFOOSUbutton`: Downloads O&O ShutUp10++ (about 82 MB) from oo-software.com on every click and launches it. Nothing is installed; the file is saved under %LocalAppData%\winutil.

## Section 5: Observations for NitrOS

- Only a few winutil items cut idle process count or RAM: svchost splitting off, Widgets and StartExperiencesApp removal, OneDrive removal, Windows AI removal, background apps off, Edge removal, the (short) service list, Phone Link / Cross Device / Teams / Copilot removal.
- Most of winutil is privacy or UI polish, not memory work.
- Current winutil does NOT broadly disable services: `WPFTweaksServices` lists only CscService, DiagTrack, MapsBroker, StorSvc, SharedAccess.
- Conflict: `WPFTweaksIPv46`, `WPFTweaksTeredo`, `WPFTweaksDisableIPv6` all write `HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip6\Parameters` `DisabledComponents` (32 / 1 / 255); only one can win.
- ROG Xbox Ally X: avoid removing `Microsoft.GamingApp`, `Microsoft.XboxGamingOverlay`, `Microsoft.XboxIdentityProvider`, `Microsoft.Xbox.TCUI`; winutil itself says svchost splitting disable can interfere with Xbox services; `SharedAccess` disabled breaks hotspot sharing; S3 sleep, Ultimate Performance plan and notification disable are risky on a handheld.
- Not read in detail: bodies of Set-WinUtilDNS, Invoke-WPFOOSU, ultimate performance button functions, Set-WinUtilService, toggle runtime logic.
